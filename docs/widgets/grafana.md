## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Grafana version | `version` | Number | A choice in the dialog: 10.4 or earlier (`1`, the default when left out), Later than 10.4 (`2`). Which Grafana you run, so the widget uses the matching API. Homepage can't detect it. |
| Alerts | `alerts` | Text | Example: `alertmanager`. |
| Service URL | `url` | Text | Example: `http://grafana.host.or.ip:port`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `dashboards`, `datasources`, `totalalerts`, `alertstriggered`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: grafana
  version: 2 # optional, default is 1

  username: username

```
