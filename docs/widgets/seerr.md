## What it needs

Learn more about [Seerr](https://github.com/seerr-team/seerr).

Find your API key under `Settings > General > API Key`.

_Jellyseerr and Overseerr merged into Seerr. Use `type: seerr` (legacy `type: jellyseerr` and `type: overseerr` are aliased)._

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://seerr.host.or.ip`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `pending`, `approved`, `available`, `completed`, `processing`, `issues`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_seerr_key` | `HOMEPAGE_FILE_SEERR_KEY: /run/secrets/homepage_seerr_key` | `{{HOMEPAGE_FILE_SEERR_KEY}}` |

For a second Seerr with different credentials, add a suffix such as `_2` to each name.
