# qui

## What it needs

Learn more about [qui](https://github.com/autobrr/qui).

Generate an API key in qui under **Settings → API Keys**.

The widget has two modes:

- **Aggregated (default):** omit `instance` to show combined stats across all qBittorrent instances monitored by qui.
- **Per-instance:** set `instance` to the qui ID (visible in the qui UI) to show just that one.

#### Fields

Default fields: `["leech", "download", "seed", "upload"]`.

Note: `ratio` and `freeSpace` are only available with the 'single instance' version of the widget.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://qui.host.or.ip:7476`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Instance | `instance` | Number | Example: `1`. |
| Visible fields | `fields` | List | Choices: `leech`, `download`, `seed`, `upload`, `total`, `errored`, `ratio`, `freeSpace`. The widget shows them in the order you list them. Leave unset for its usual fields. |
