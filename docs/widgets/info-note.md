# Note

Text you write yourself, with links.

Information widget · type `note` · Made by Studio

[All widgets](README.md)

## What it needs

Text you write yourself, such as a reminder, the guest Wi-Fi or on-call numbers. Everyone who can see the dashboard can read it, so keep passwords and keys out of it.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Text | `text` | Text | Plain text. Line breaks are kept, and web addresses (https://…) become links. Nothing in it is read as HTML. Example: `Guest Wi-Fi: Garden https://wiki.example.org`. |
| Text size | `text_size` | Text | A choice in the dialog: Extra small (`xs`), Small (`sm`, the default when left out), Medium (`md`), Large (`lg`), Extra large (`xl`), 2× large (`2xl`), 3× large (`3xl`), 4× large (`4xl`). |

## Examples

As Studio writes it in widgets.yaml. Values are examples, not defaults.

```yaml
- note:
    text: |
      Guest Wi-Fi: Garden
      https://wiki.example.org
```
