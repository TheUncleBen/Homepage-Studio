# Komga

Comics server. Libraries, Series, Books.

Integration · type `komga` · [Homepage documentation](https://gethomepage.dev/widgets/services/komga/)

[All widgets](README.md)

## What it needs

> **Studio note:** Username plus password takes precedence over key. Clear both when choosing API-key authentication.

Learn more about [Komga](https://github.com/gotson/komga).

Uses the same username and password used to login from the web.

| Komga API Version | Homepage Widget Version |
| --- | --- |
| < v2 | 1 (default) |
| >= v2 | 2 |

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://komga.host.or.ip:port`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `libraries`, `series`, `books`. Leave unset for its usual fields. |
| Komga API version | `version` | Number | A choice in the dialog: Before v2 (`1`, the default when left out), v2 or later (`2`). Which Komga API version your server offers, so the widget uses the matching API. Homepage can't detect it. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_komga_password` | `HOMEPAGE_FILE_KOMGA_PASSWORD: /run/secrets/homepage_komga_password` | `{{HOMEPAGE_FILE_KOMGA_PASSWORD}}` |
| API key | `homepage_komga_key` | `HOMEPAGE_FILE_KOMGA_KEY: /run/secrets/homepage_komga_key` | `{{HOMEPAGE_FILE_KOMGA_KEY}}` |

For a second Komga with different credentials, add a suffix such as `_2` to each name.
