# PhotoPrism

Photo library. Albums, Photos, Videos, People.

Integration · type `photoprism` · [Homepage documentation](https://gethomepage.dev/widgets/services/photoprism/)

[All widgets](README.md)

## What it needs

> **Studio note:** Username plus password takes precedence over key. Clear both when choosing an app password.

Learn more about [PhotoPrism](https://github.com/photoprism/photoprism).

Authentication is possible via [app passwords](https://docs.photoprism.app/user-guide/settings/account/#apps-and-devices) or username/password.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://photoprism.host.or.ip:port`. |
| Username | `username` | Text | Example: `admin`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `albums`, `photos`, `videos`, `people`. Leave unset for its usual fields. |
| App password | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. PhotoPrism app password. Omit username and password when using this authentication method. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_photoprism_password` | `HOMEPAGE_FILE_PHOTOPRISM_PASSWORD: /run/secrets/homepage_photoprism_password` | `{{HOMEPAGE_FILE_PHOTOPRISM_PASSWORD}}` |
| App password | `homepage_photoprism_key` | `HOMEPAGE_FILE_PHOTOPRISM_KEY: /run/secrets/homepage_photoprism_key` | `{{HOMEPAGE_FILE_PHOTOPRISM_KEY}}` |

For a second PhotoPrism with different credentials, add a suffix such as `_2` to each name.
