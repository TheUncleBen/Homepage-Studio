## What it needs

[Backrest](https://garethgeorge.github.io/backrest/) is a web-based frontend for the [Restic](https://restic.net/) backup tool.

**Allowed fields:** `["num_success_latest","num_failure_latest","num_success_30","num_plans","num_failure_30","bytes_added_30"]`
