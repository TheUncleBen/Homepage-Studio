# Zabbix

Infrastructure monitoring. Not classified, Information, Warning, Average, High, Disaster.

Integration · type `zabbix` · [Homepage documentation](https://gethomepage.dev/widgets/services/zabbix/)

[All widgets](README.md)

## What it needs

Learn more about [Zabbix](https://github.com/zabbix/zabbix). The widget supports (at least) Zabbix server version 7.0.

---

Only 4 fields can be shown at a time, with the default being: `["warning", "average", "high", "disaster"]`.

See the [Zabbix documentation](https://www.zabbix.com/documentation/current/en/manual/web_interface/frontend_sections/users/api_tokens) for details on generating API tokens.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://zabbix.host.or.ip/zabbix`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `unclassified`, `information`, `warning`, `average`, `high`, `disaster`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_zabbix_key` | `HOMEPAGE_FILE_ZABBIX_KEY: /run/secrets/homepage_zabbix_key` | `{{HOMEPAGE_FILE_ZABBIX_KEY}}` |

For a second Zabbix with different credentials, add a suffix such as `_2` to each name.
