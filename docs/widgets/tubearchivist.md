## What it needs

Learn more about [Tube Archivist](https://github.com/tubearchivist/tubearchivist).

You must be running at least version 0.4.4

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://tubearchivist.host.or.ip`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `downloads`, `videos`, `channels`, `playlists`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_tubearchivist_key` | `HOMEPAGE_FILE_TUBEARCHIVIST_KEY: /run/secrets/homepage_tubearchivist_key` | `{{HOMEPAGE_FILE_TUBEARCHIVIST_KEY}}` |

For a second Tube Archivist with different credentials, add a suffix such as `_2` to each name.
