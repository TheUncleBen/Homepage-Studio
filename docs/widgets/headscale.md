# Headscale

Tailscale control server. Name, Address, Last Seen, Status.

Integration · type `headscale` · [Homepage documentation](https://gethomepage.dev/widgets/services/headscale/)

[All widgets](README.md)

## What it needs

Learn more about [Headscale](https://headscale.net/).

You will need to generate an API access token from the [command line](https://headscale.net/ref/remote-cli/#create-an-api-key) using `headscale apikeys create` command.

To find your node ID, you can use `headscale nodes list` command.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://headscale.host.or.ip:port`. |
| Node Id | `nodeId` | Text | Example: `nodeid`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `name`, `address`, `last_seen`, `status`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_headscale_key` | `HOMEPAGE_FILE_HEADSCALE_KEY: /run/secrets/homepage_headscale_key` | `{{HOMEPAGE_FILE_HEADSCALE_KEY}}` |

For a second Headscale with different credentials, add a suffix such as `_2` to each name.
