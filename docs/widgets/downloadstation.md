# Synology Download Station

Download manager. Leech, Download, Seed, Upload.

## What it needs

Learn more about [Synology Download Station](https://www.synology.com/en-us/dsm/packages/DownloadStation).

Note: the widget is not compatible with 2FA.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://downloadstation.host.or.ip:port`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `leech`, `download`, `seed`, `upload`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_downloadstation_password` | `HOMEPAGE_FILE_DOWNLOADSTATION_PASSWORD: /run/secrets/homepage_downloadstation_password` | `{{HOMEPAGE_FILE_DOWNLOADSTATION_PASSWORD}}` |

For a second Synology Download Station with different credentials, add a suffix such as `_2` to each name.
