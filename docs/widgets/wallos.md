# Wallos

Subscription tracker. Subscriptions, Next Payment, Prev. Month, This Month, Next Month.

Integration · type `wallos` · [Homepage documentation](https://gethomepage.dev/widgets/services/wallos/)

[All widgets](README.md)

## What it needs

Learn more about [Wallos](https://github.com/ellite/wallos).

If you're using more than one currency to record subscriptions then you should also have your "Fixer API" key set-up (`Settings > Fixer API Key`).

> **Please Note:** The monthly cost displayed is the total cost of subscriptions in that month, **not** the _"monthly"_ average cost.

Get your API key under `Profile > API Key`.

Default fields: `["activeSubscriptions", "nextRenewingSubscription", "thisMonthlyCost", "nextMonthlyCost"]`.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://wallos.host.or.ip`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `activeSubscriptions`, `nextRenewingSubscription`, `previousMonthlyCost`, `thisMonthlyCost`, `nextMonthlyCost`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_wallos_key` | `HOMEPAGE_FILE_WALLOS_KEY: /run/secrets/homepage_wallos_key` | `{{HOMEPAGE_FILE_WALLOS_KEY}}` |

For a second Wallos with different credentials, add a suffix such as `_2` to each name.
