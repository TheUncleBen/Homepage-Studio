| Setting | YAML key | Type | Notes |

| Service URL | `url` | Text | Example: `http[s]://slskd.host.or.ip[:5030]`. |

| Visible fields | `fields` | List | Choices: `slskStatus`, `updateStatus`, `downloads`, `uploads`, `sharedFiles`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_slskd_key` | `HOMEPAGE_FILE_SLSKD_KEY: /run/secrets/homepage_slskd_key` | `{{HOMEPAGE_FILE_SLSKD_KEY}}` |

For a second Slskd with different credentials, add a suffix such as `_2` to each name.
