# Plex

Media server. Active Streams, Albums, Movies, TV Shows.

Integration · type `plex` · [Homepage documentation](https://gethomepage.dev/widgets/services/plex/)

[All widgets](README.md)

## What it needs

Learn more about [Plex](https://www.plex.tv/).

The core Plex API is somewhat limited but basic info regarding library sizes and the number of active streams is supported. For more detailed info regarding active streams see the [Plex Tautulli widget](https://gethomepage.dev/widgets/services/plex-tautulli/).

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://plex.host.or.ip:32400`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `streams`, `albums`, `movies`, `tv`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_plex_key` | `HOMEPAGE_FILE_PLEX_KEY: /run/secrets/homepage_plex_key` | `{{HOMEPAGE_FILE_PLEX_KEY}}` |

For a second Plex with different credentials, add a suffix such as `_2` to each name.
