[All widgets](README.md)

## What it needs

Learn more about [Plex](https://www.plex.tv/).

The core Plex API is somewhat limited but basic info regarding library sizes and the number of active streams is supported. For more detailed info regarding active streams see the [Plex Tautulli widget](https://gethomepage.dev/widgets/services/plex-tautulli/).

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://plex.host.or.ip:32400`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `streams`, `albums`, `movies`, `tv`. The widget shows them in the order you list them. Leave unset for its usual fields. |
