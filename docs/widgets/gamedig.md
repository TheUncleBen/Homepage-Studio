# GameDig

Integration · type `gamedig` · [Homepage documentation](https://gethomepage.dev/widgets/services/gamedig/)

[All widgets](README.md)

## What it needs

Learn more about [GameDig](https://github.com/gamedig/node-gamedig).

Uses the [GameDig](https://www.npmjs.com/package/gamedig) library to get game server information for any supported server type.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Server Type | `serverType` | Text | Example: `csgo`. |
| Service URL | `url` | Text | Example: `udp://server.host.or.ip:port`. |
| Visible fields | `fields` | List | Choices: `status`, `name`, `map`, `currentPlayers`, `players`, `maxPlayers`, `bots`, `ping`. The widget shows them in the order you list them, up to 4. Leave unset for its usual fields. |
| Game token | `gameToken` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. Optional GameDig token for server types that require one. Leave unset for other games. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: gamedig
  serverType: csgo # see https://github.com/gamedig/node-gamedig#games-list
  url: udp://server.host.or.ip:port
  gameToken: # optional, a token used by gamedig with certain games
```
