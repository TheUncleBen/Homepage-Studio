## Settings

| Setting | YAML key | Type | Notes |

| Profile | `profile` | Text | Example: `profileid`. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_nextdns_key` | `HOMEPAGE_FILE_NEXTDNS_KEY: /run/secrets/homepage_nextdns_key` | `{{HOMEPAGE_FILE_NEXTDNS_KEY}}` |

For a second NextDNS with different credentials, add a suffix such as `_2` to each name.
