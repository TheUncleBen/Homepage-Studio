# Moonraker (Klipper)

3D printer (Klipper). Printer State, Print Status, Progress, Layers.

Integration · type `moonraker` · [Homepage documentation](https://gethomepage.dev/widgets/services/moonraker/)

[All widgets](README.md)

## What it needs

Learn more about [Moonraker](https://github.com/Arksine/moonraker).

If your moonraker instance has an active authorization and your homepage ip isn't whitelisted you need to add your api key ([Authorization Documentation](https://moonraker.readthedocs.io/en/latest/web_api/#authorization)).

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://moonraker.host.or.ip:port`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `printer_state`, `print_status`, `print_progress`, `layers`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_moonraker_key` | `HOMEPAGE_FILE_MOONRAKER_KEY: /run/secrets/homepage_moonraker_key` | `{{HOMEPAGE_FILE_MOONRAKER_KEY}}` |

For a second Moonraker (Klipper) with different credentials, add a suffix such as `_2` to each name.
