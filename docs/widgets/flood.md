## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_flood_password` | `HOMEPAGE_FILE_FLOOD_PASSWORD: /run/secrets/homepage_flood_password` | `{{HOMEPAGE_FILE_FLOOD_PASSWORD}}` |

For a second Flood with different credentials, add a suffix such as `_2` to each name.
