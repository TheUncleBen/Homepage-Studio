## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_whatsupdocker_password` | `HOMEPAGE_FILE_WHATSUPDOCKER_PASSWORD: /run/secrets/homepage_whatsupdocker_password` | `{{HOMEPAGE_FILE_WHATSUPDOCKER_PASSWORD}}` |
| API key | `homepage_whatsupdocker_key` | `HOMEPAGE_FILE_WHATSUPDOCKER_KEY: /run/secrets/homepage_whatsupdocker_key` | `{{HOMEPAGE_FILE_WHATSUPDOCKER_KEY}}` |

For a second What's Up Docker with different credentials, add a suffix such as `_2` to each name.
