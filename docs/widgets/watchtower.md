# Watchtower

Container updates. Scanned, Updated, Failed.

Integration · type `watchtower` · [Homepage documentation](https://gethomepage.dev/widgets/services/watchtower/)

[All widgets](README.md)

## What it needs

Learn more about [Watchtower](https://github.com/nicholas-fedor/watchtower).

To use this widget, Watchtower needs to be configured to [enable metrics](https://watchtower.nickfedor.com/dev/advanced-features/metrics-api/).

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://your-ip-address:8080`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `containers_scanned`, `containers_updated`, `containers_failed`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_watchtower_key` | `HOMEPAGE_FILE_WATCHTOWER_KEY: /run/secrets/homepage_watchtower_key` | `{{HOMEPAGE_FILE_WATCHTOWER_KEY}}` |

For a second Watchtower with different credentials, add a suffix such as `_2` to each name.
