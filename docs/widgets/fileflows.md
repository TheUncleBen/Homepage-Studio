## What it needs

Learn more about [FileFlows](https://github.com/revenz/FileFlows).

| FileFlows Version | Homepage Widget Version |
| --- | --- |
| < 26.10 | 1 (default) |
| >= 26.10 | 2 |

Version 2 uses the ["Fenrus Dashboard Endpoint"](https://fileflows.com/docs/webconsole/config/settings/general#fenrus-dashboard-endpoint), which must be enabled. Use the token shown there as the `key`.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://your.fileflows.host:port`. |
| Version | `version` | Number | Example: `2`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `queue`, `processing`, `processed`, `time`. The widget shows them in the order you list them. Leave unset for its usual fields. |
