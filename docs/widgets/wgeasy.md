## What it needs

Learn more about [Wg-Easy](https://github.com/wg-easy/wg-easy).

Note: by default `["connected", "enabled", "total"]` are displayed.

To detect if a device is connected the time since the last handshake is queried. `threshold` is the time to wait in minutes since the last handshake to consider a device connected. Default is 2 minutes.

| Wg-Easy API Version | Homepage Widget Version |
| --- | --- |
| < v15 | 1 (default) |
| >= v15 | 2 |

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://wg.easy.or.ip`. |
| wg-easy version | `version` | Number | A choice in the dialog: Before 15 (`1`, the default when left out), 15 or later (`2`). Which wg-easy you run, so the widget uses the matching API. Homepage can't detect it. |
| Username | `username` | Text | Example: `yourwgusername`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Threshold | `threshold` | Number | Example: `2`. |
| Visible fields | `fields` | List | Choices: `connected`, `enabled`, `disabled`, `total`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples
