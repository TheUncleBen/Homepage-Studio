## What it needs

Learn more about [Ghostfolio](https://github.com/ghostfolio/ghostfolio).

Authentication requires manually obtaining a Bearer token which can be obtained by make a POST request to the API e.g.

```
curl -X POST http://localhost:3333/api/v1/auth/anonymous -H 'Content-Type: application/json' -d '{ "accessToken": "SECURITY_TOKEN_OF_ACCOUNT" }'
```

See the [official docs](https://github.com/ghostfolio/ghostfolio#authorization-bearer-token).

_Note that the Bearer token is valid for 6 months, after which a new one must be generated._

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://ghostfoliohost:port`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `gross_percent_today`, `gross_percent_1y`, `gross_percent_max`, `net_worth`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_ghostfolio_key` | `HOMEPAGE_FILE_GHOSTFOLIO_KEY: /run/secrets/homepage_ghostfolio_key` | `{{HOMEPAGE_FILE_GHOSTFOLIO_KEY}}` |

For a second Ghostfolio with different credentials, add a suffix such as `_2` to each name.
