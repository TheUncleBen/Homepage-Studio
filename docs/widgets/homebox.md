# Homebox

Integration · type `homebox` · [Homepage documentation](https://gethomepage.dev/widgets/services/homebox/)

[All widgets](README.md)

## What it needs

Learn more about [Homebox](https://github.com/hay-kot/homebox).

Uses the same username and password used to login from the web.

The `totalValue` field will attempt to format using the currency you have configured in Homebox.

If more than 4 fields are provided, only the first 4 are displayed.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://homebox.host.or.ip:port`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `items`, `totalWithWarranty`, `locations`, `labels`, `users`, `totalValue`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: homebox
  url: http://homebox.host.or.ip:port
  username: username
  password: password
  fields: ["items", "locations", "totalValue"] # optional - default fields shown
```
