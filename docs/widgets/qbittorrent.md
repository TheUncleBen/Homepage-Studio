# qBittorrent

[All widgets](README.md)

## What it needs

Learn more about [qBittorrent](https://github.com/qbittorrent/qBittorrent).

Authenticate using the WebUI username and password or the API Key `(qBittorrent ≥ v5.2.0)`.

API Key is located in `Options > WebUI > Authentication > API Key`.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://qbittorrent.host.or.ip`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Enable Leech Progress | `enableLeechProgress` | On/off | Example: `true`. |
| Enable Leech Size | `enableLeechSize` | On/off | Example: `true`. |
| Visible fields | `fields` | List | Choices: `leech`, `download`, `seed`, `upload`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: qbittorrent
  url: http://qbittorrent.host.or.ip
  username: username
  password: password
  key: qbt_apikey # required if using API key instead of username/password
  enableLeechProgress: true # optional, defaults to false
  enableLeechSize: true # optional, defaults to false
```
