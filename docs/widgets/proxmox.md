## What it needs

Learn more about [Proxmox](https://www.proxmox.com/en/).

This widget shows the running and total counts of both QEMU VMs and LX Containers in the Proxmox cluster. It also shows the CPU and memory usage of the first node in the cluster.

See the [Proxmox configuration documentation](https://gethomepage.dev/configs/proxmox/#create-token) for details on creating API tokens.

Use `username@pam!Token ID` as the `username` (e.g `api@pam!homepage`) setting and `Secret` as the `password` setting.

You can set the optional `node` setting when you want to show metrics for a single node. By default it will show the average for the complete cluster.

| Service URL | `url` | Text | Example: `https://proxmox.host.or.ip:8006`. |

| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Node | `node` | Text | Example: `pve-1`. |
| Visible fields | `fields` | List | Choices: `vms`, `lxc`, `resources.cpu`, `resources.mem`. The widget shows them in the order you list them. Leave unset for its usual fields. |
