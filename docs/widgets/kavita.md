## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_kavita_password` | `HOMEPAGE_FILE_KAVITA_PASSWORD: /run/secrets/homepage_kavita_password` | `{{HOMEPAGE_FILE_KAVITA_PASSWORD}}` |
| API key | `homepage_kavita_key` | `HOMEPAGE_FILE_KAVITA_KEY: /run/secrets/homepage_kavita_key` | `{{HOMEPAGE_FILE_KAVITA_KEY}}` |

For a second Kavita with different credentials, add a suffix such as `_2` to each name.
