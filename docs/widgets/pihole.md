# Pi-hole

DNS ad blocker. Queries, Blocked, Blocked %, Gravity.

Integration · type `pihole` · [Homepage documentation](https://gethomepage.dev/widgets/services/pihole/)

[All widgets](README.md)

## What it needs

Learn more about [PiHole](https://github.com/pi-hole/pi-hole).

Note: by default the "blocked" and "blocked_percent" fields are merged e.g. "1,234 (15%)" but explicitly including the "blocked_percent" field will change them to display separately.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://pi.hole.or.ip`. |
| Pi-hole version | `version` | Number | A choice in the dialog: Pi-hole 5 (`5`, the default when left out), Pi-hole 6 or later (`6`). Which Pi-hole you run, so the widget uses the matching API. Homepage can't detect it. With Pi-hole 6 the key can be your password or an app password. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `queries`, `blocked`, `blocked_percent`, `gravity`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_pihole_key` | `HOMEPAGE_FILE_PIHOLE_KEY: /run/secrets/homepage_pihole_key` | `{{HOMEPAGE_FILE_PIHOLE_KEY}}` |

For a second Pi-hole with different credentials, add a suffix such as `_2` to each name.

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: pihole
  url: http://pi.hole.or.ip
  version: 6 # required if running v6 or higher, defaults to 5
  key: yourpiholeapikey # optional, in v6 can be your password or app password
```
