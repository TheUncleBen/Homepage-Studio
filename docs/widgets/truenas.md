## What it needs

Learn more about [TrueNas](https://www.truenas.com/).

| TrueNAS Version | Homepage widget version |
| --- | --- |
| < 26.04 (REST API) | 1 (default) |
| > 25.04 (Websocket API) | 2 |

To create an API Key, follow [the official TrueNAS documentation](https://www.truenas.com/docs/scale/scaletutorials/toptoolbar/managingapikeys/).

A detailed pool listing is disabled by default, but can be enabled with the `enablePools` option.

To use the `enablePools` option with TrueNAS Core, the `nasType` parameter is required.

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |

| Service URL | `url` | Text | Example: `http://truenas.host.or.ip`. |
| Version | `version` | Number | Example: `2`. |
| Username | `username` | Text | Example: `user`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Enable Pools | `enablePools` | On/off | Example: `true`. |
| Nas Type | `nasType` | Text | Example: `scale`. |
| Visible fields | `fields` | List | Choices: `load`, `uptime`, `alerts`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: truenas
  url: http://truenas.host.or.ip
  version: 2 # optional, defaults to 1
  username: user # not required if using api key
  password: pass # not required if using api key
  key: yourtruenasapikey # not required if using username / password
  enablePools: true # optional, defaults to false
  nasType: scale # defaults to scale, must be set to 'core' if using enablePools with TrueNAS Core
```
