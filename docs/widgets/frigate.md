## What it needs

A recent event listing is disabled by default, but can be enabled with the `enableRecentEvents` option.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://frigate.host.or.ip:port`. |
| Enable Recent Events | `enableRecentEvents` | On/off | Example: `true`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `cameras`, `uptime`, `version`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_frigate_password` | `HOMEPAGE_FILE_FRIGATE_PASSWORD: /run/secrets/homepage_frigate_password` | `{{HOMEPAGE_FILE_FRIGATE_PASSWORD}}` |

For a second Frigate with different credentials, add a suffix such as `_2` to each name.
