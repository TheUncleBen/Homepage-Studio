# Booklore

Book library. Libraries, Books, Reading, Finished.

Integration · type `booklore` · [Homepage documentation](https://gethomepage.dev/widgets/services/booklore/)

[All widgets](README.md)

## What it needs

Learn more about [Booklore](https://github.com/booklore-app/booklore).

The widget authenticates with your Booklore credentials to surface total libraries, books, and reading progress counts for your account.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `https://booklore.host.or.ip`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_booklore_password` | `HOMEPAGE_FILE_BOOKLORE_PASSWORD: /run/secrets/homepage_booklore_password` | `{{HOMEPAGE_FILE_BOOKLORE_PASSWORD}}` |

For a second Booklore with different credentials, add a suffix such as `_2` to each name.
