# Audiobookshelf

Audiobook and podcast server. Podcasts, Duration, Books.

Integration · type `audiobookshelf` · [Homepage documentation](https://gethomepage.dev/widgets/services/audiobookshelf/)

[All widgets](README.md)

## What it needs

Learn more about [Audiobookshelf](https://github.com/advplyr/audiobookshelf).

You can find your API token by logging into the Audiobookshelf web app as an admin, go to the config → users page, and click on your account.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://audiobookshelf.host.or.ip:port`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `podcasts`, `podcastsDuration`, `books`, `booksDuration`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_audiobookshelf_key` | `HOMEPAGE_FILE_AUDIOBOOKSHELF_KEY: /run/secrets/homepage_audiobookshelf_key` | `{{HOMEPAGE_FILE_AUDIOBOOKSHELF_KEY}}` |

For a second Audiobookshelf with different credentials, add a suffix such as `_2` to each name.
