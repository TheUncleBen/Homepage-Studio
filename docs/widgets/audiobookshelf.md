## What it needs

Learn more about [Audiobookshelf](https://github.com/advplyr/audiobookshelf).

You can find your API token by logging into the Audiobookshelf web app as an admin, go to the config → users page, and click on your account.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://audiobookshelf.host.or.ip:port`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `podcasts`, `podcastsDuration`, `books`, `booksDuration`. The widget shows them in the order you list them. Leave unset for its usual fields. |
