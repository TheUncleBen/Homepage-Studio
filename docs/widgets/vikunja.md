## What it needs

Learn more about [Vikunja](https://vikunja.io).

A list of the next 5 tasks ordered by due date is disabled by default, but can be enabled with the `enableTaskList` option.

| Vikunja Version | Homepage Widget Version |
| --- | --- |
| < v1.0.0-rc4 | 1 (default) |
| >= v1.0.0-rc4 | 2 |

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http[s]://vikunja.host.or.ip[:port]`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Enable Task List | `enableTaskList` | On/off | Example: `true`. |
| Version | `version` | Number | Example: `2`. |
| Visible fields | `fields` | List | Choices: `projects`, `tasks7d`, `tasksOverdue`, `tasksInProgress`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

widget:
