# Azure DevOps

Pipelines and pull requests. Result, Status.

Integration · type `azuredevops` · [Homepage documentation](https://gethomepage.dev/widgets/services/azuredevops/)

[All widgets](README.md)

## What it needs

Learn more about [Azure DevOps](https://azure.microsoft.com/en-us/products/devops).

This widget has 2 functions:

1. Pipelines: checks if the relevant pipeline is running or not, and if not, reports the last status. Allowed fields: `["result", "status"]`.

1. Pull Requests: returns the amount of open PRs, the amount of the PRs you have open, and how many PRs that you open are marked as 'Approved' by at least 1 person and not yet completed. Allowed fields: `["totalPrs", "myPrs", "approved"]`.

You will need to generate a personal access token for an existing user, see the [azure documentation](https://learn.microsoft.com/en-us/azure/devops/organizations/accounts/use-personal-access-tokens-to-authenticate?view=azure-devops&tabs=Windows#create-a-pat)

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_azuredevops_key` | `HOMEPAGE_FILE_AZUREDEVOPS_KEY: /run/secrets/homepage_azuredevops_key` | `{{HOMEPAGE_FILE_AZUREDEVOPS_KEY}}` |

For a second Azure DevOps with different credentials, add a suffix such as `_2` to each name.
