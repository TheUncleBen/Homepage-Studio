| Setting | YAML key | Type | Notes |

| Service URL | `url` | Text | Example: `http://dispatcharr.host.or.ip`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Enable Active Streams | `enableActiveStreams` | On/off | Example: `true`. |
| Visible fields | `fields` | List | Choices: `channels`, `streams`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_dispatcharr_password` | `HOMEPAGE_FILE_DISPATCHARR_PASSWORD: /run/secrets/homepage_dispatcharr_password` | `{{HOMEPAGE_FILE_DISPATCHARR_PASSWORD}}` |

For a second Dispatcharr with different credentials, add a suffix such as `_2` to each name.
