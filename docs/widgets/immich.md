# Immich

Photo library. Users, Photos, Videos, Storage.

Integration · type `immich` · [Homepage documentation](https://gethomepage.dev/widgets/services/immich/)

[All widgets](README.md)

## What it needs

Learn more about [Immich](https://github.com/immich-app/immich).

| Immich Version | Homepage Widget Version |
| --- | --- |
| < v1.118 | 1 (default) |
| >= v1.118 | 2 |

Find your API key under `Account Settings > API Keys`. The key should have the `server.statistics` permission.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://immich.host.or.ip`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Immich version | `version` | Number | A choice in the dialog: Before 1.118 (`1`, the default when left out), 1.118 or later (`2`). Which Immich you run, so the widget uses the matching API. Homepage can't detect it. |
| Visible fields | `fields` | List | Choices: `users`, `photos`, `videos`, `storage`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_immich_key` | `HOMEPAGE_FILE_IMMICH_KEY: /run/secrets/homepage_immich_key` | `{{HOMEPAGE_FILE_IMMICH_KEY}}` |

For a second Immich with different credentials, add a suffix such as `_2` to each name.
