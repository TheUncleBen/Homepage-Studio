## What it needs

Learn more about [PeaNUT](https://github.com/Brandawg93/PeaNUT).

This widget adds support for [Network UPS Tools](https://networkupstools.org/) via a third party tool, [PeaNUT](https://github.com/Brandawg93/PeaNUT).

The default ups name is `ups`. To configure more than one ups, you must create multiple peanut services.

> **Note**
>
> This widget requires an additional tool, [PeaNUT](https://github.com/Brandawg93/PeaNUT), as noted. Other projects exist to achieve similar results using a `customapi` widget, for example [NUTCase](https://github.com/ArthurMitchell42/nutcase#using-nutcase-homepage).

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://peanut.host.or.ip:port`. |
| UPS name | `key` | Text | The UPS name, not an API credential. The documented default is ups. Example: `nameofyourups`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `battery_charge`, `ups_load`, `ups_status`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: peanut
  url: http://peanut.host.or.ip:port
  key: nameofyourups
  username: username # only needed if set
  password: password # only needed if set
```
