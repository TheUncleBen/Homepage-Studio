# Dockhand

Integration · type `dockhand` · [Homepage documentation](https://gethomepage.dev/widgets/services/dockhand/)

[All widgets](README.md)

## What it needs

Learn more about [Dockhand](https://dockhand.pro/).

Note: The widget currently supports Dockhand's **local** authentication only.

**Allowed fields:** (max 4): `running`, `stopped`, `paused`, `total`, `cpu`, `memory`, `images`, `volumes`, `events_today`, `pending_updates`, `stacks`. **Default fields:** `running`, `total`, `cpu`, `memory`.

## Settings

| Setting | YAML key | Type | Notes |

| Service URL | `url` | Text | Example: `http://localhost:3001`. |
| Environment | `environment` | Text | Example: `local`. |
| Username | `username` | Text | Example: `your-user`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `running`, `stopped`, `paused`, `total`, `cpu`, `memory`, `images`, `volumes`, `events_today`, `pending_updates`, `stacks`. The widget shows them in the order you list them, up to 4. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: dockhand
  url: http://localhost:3001
  environment: local # optional: name or id; aggregates all when omitted
  username: your-user # required for local auth
  password: your-pass # required for local auth

```
