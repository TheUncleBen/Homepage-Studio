## What it needs

> **Studio note:** CPU and memory describe container usage. Disks must be mounted into the Homepage container. Glances provides separate host/remote statistics.

You can include all or some of the available resources. If you do not want to see that resource, simply pass `false`.

The disk path is the path reported by `df` (Mounted On), or the mount point of the disk.

> **Note**
>
> Any disk you wish to access must be mounted to your container as a volume.

The cpu and memory resource information are the container's usage while [glances](https://gethomepage.dev/widgets/info/glances/) displays statistics for the host machine on which it is installed.

The resources widget primarily relies on a popular tool called [systeminformation](https://systeminformation.io). Thus, any limitiations of that software apply, for example, BRTFS RAID is not supported for the disk usage. In this case users may want to use the [glances widget](https://gethomepage.dev/widgets/info/glances/) instead.

> **Warning**
>
> The package used for getting CPU temp ([systeminformation](https://systeminformation.io)) is not compatible with some setups and will not report any value(s) for CPU temp.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Cpu | `cpu` | On/off | Example: `true`. |
| Memory | `memory` | On/off | Example: `true`. |
| Disk | `disk` | Text or List | Example: `/disk/mount/path`. |
| Cputemp | `cputemp` | On/off | Example: `true`. |
| Tempmin | `tempmin` | Number | Example: `0`. |
| Tempmax | `tempmax` | Number | Example: `100`. |
| Uptime | `uptime` | On/off | Example: `true`. |
| Units | `units` | Text | Example: `imperial`. |
| Refresh | `refresh` | Number | Example: `3000`. |
| Disk Units | `diskUnits` | Text | Example: `bytes`. |
| Network | `network` | On/off or Text | false disables network; true uses the default interface; a string selects an interface. A named host interface requires the documented read-only /sys mount. Example: `true`. |
| Label | `label` | Text | Example: `System`. |
| Expanded | `expanded` | On/off | Example: `true`. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
- resources:
    cpu: true
    memory: true
    disk: /disk/mount/path
    cputemp: true
    tempmin: 0 # optional, minimum cpu temp
    tempmax: 100 # optional, maximum cpu temp
    uptime: true
    units: imperial # only used by cpu temp, options: 'imperial' or 'metric'
    refresh: 3000 # optional, in ms
    diskUnits: bytes # optional, bytes (default) or bbytes. Only applies to disk
    network: true # optional, uses 'default' if true or specify a network interface name
```

```yaml
- resources:
    label: System
    cpu: true
    memory: true

- resources:
    label: Storage
    disk: /mnt/storage
```

```yaml
- resources:
    label: Storage
    disk:
      - /mnt/storage
      - /mnt/backup
      - /mnt/media
```

```yaml
- resources:
    label: Array Disks
    expanded: true
    disk:
      - /disk1
      - /disk2
      - /disk3
```
