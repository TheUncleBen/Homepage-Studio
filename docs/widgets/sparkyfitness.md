## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_sparkyfitness_key` | `HOMEPAGE_FILE_SPARKYFITNESS_KEY: /run/secrets/homepage_sparkyfitness_key` | `{{HOMEPAGE_FILE_SPARKYFITNESS_KEY}}` |

For a second SparkyFitness with different credentials, add a suffix such as `_2` to each name.
