# Proxmox Backup Server

Integration · type `proxmoxbackupserver` · [Homepage documentation](https://gethomepage.dev/widgets/services/proxmoxbackupserver/)

[All widgets](README.md)

## What it needs

Learn more about [Proxmox Backup Server](https://www.proxmox.com/en/proxmox-backup-server/overview).

Create a user and an API token similar to the [Proxmox VE description](https://gethomepage.dev/widgets/services/proxmox/). The "Audit" role is required for both the user and token (not group).

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `https://proxmoxbackupserver.host:port`. |
| Username | `username` | Text | Example: `api_token_id`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Datastore | `datastore` | Text | Example: `datastore_name`. |
| Visible fields | `fields` | List | Choices: `datastore_usage`, `failed_tasks_24h`, `cpu_usage`, `memory_usage`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: proxmoxbackupserver
  url: https://proxmoxbackupserver.host:port
  username: api_token_id
  password: api_token_secret
  datastore: datastore_name #optional; if omitted, will display a combination of all datastores used / total
```
