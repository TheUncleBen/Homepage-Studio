## What it needs

Learn more about [Firefly III](https://www.firefly-iii.org/).

Find your API key under `Options > Profile > OAuth > Personal Access Tokens`.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `https://firefly.host.or.ip`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `networth`, `budget`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_firefly_key` | `HOMEPAGE_FILE_FIREFLY_KEY: /run/secrets/homepage_firefly_key` | `{{HOMEPAGE_FILE_FIREFLY_KEY}}` |

For a second Firefly III with different credentials, add a suffix such as `_2` to each name.
