# JDownloader

Download manager. Queue, Size, Remaining, Speed.

Integration · type `jdownloader` · [Homepage documentation](https://gethomepage.dev/widgets/services/jdownloader/)

[All widgets](README.md)

## What it needs

Learn more about [JDownloader](https://jdownloader.org/).

Basic widget to show number of items in download queue, along with the queue size and current download speed.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Username | `username` | Text | Example: `JDownloader Username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Client | `client` | Text | Example: `Name of JDownloader Instance`. |
| Visible fields | `fields` | List | Choices: `downloadCount`, `downloadTotalBytes`, `downloadBytesRemaining`, `downloadSpeed`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_jdownloader_password` | `HOMEPAGE_FILE_JDOWNLOADER_PASSWORD: /run/secrets/homepage_jdownloader_password` | `{{HOMEPAGE_FILE_JDOWNLOADER_PASSWORD}}` |

For a second JDownloader with different credentials, add a suffix such as `_2` to each name.
