# JDownloader

Integration · type `jdownloader` · [Homepage documentation](https://gethomepage.dev/widgets/services/jdownloader/)

[All widgets](README.md)

## What it needs

Learn more about [JDownloader](https://jdownloader.org/).

Basic widget to show number of items in download queue, along with the queue size and current download speed.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Username | `username` | Text | Example: `JDownloader Username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Client | `client` | Text | Example: `Name of JDownloader Instance`. |
| Visible fields | `fields` | List | Choices: `downloadCount`, `downloadTotalBytes`, `downloadBytesRemaining`, `downloadSpeed`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

widget:
  type: jdownloader
  username: JDownloader Username
  password: JDownloader Password
  client: Name of JDownloader Instance
