# Kopia

Backups. Status, Size, Last Run, Next Run.

Integration · type `kopia` · [Homepage documentation](https://gethomepage.dev/widgets/services/kopia/)

[All widgets](README.md)

## What it needs

Learn more about [Kopia](https://github.com/kopia/kopia).

You may optionally pass values for `snapshotHost` and / or `snapshotPath` to select a specific backup source for the widget.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://kopia.host.or.ip:port`. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Snapshot Host | `snapshotHost` | Text | Example: `hostname`. |
| Snapshot Path | `snapshotPath` | Text | Example: `path`. |
| Visible fields | `fields` | List | Choices: `status`, `size`, `lastrun`, `nextrun`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_kopia_password` | `HOMEPAGE_FILE_KOPIA_PASSWORD: /run/secrets/homepage_kopia_password` | `{{HOMEPAGE_FILE_KOPIA_PASSWORD}}` |

For a second Kopia with different credentials, add a suffix such as `_2` to each name.

## Examples

From Homepage's documentation. Values are examples, not defaults.

widget:
