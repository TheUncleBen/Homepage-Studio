## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_checkmk_password` | `HOMEPAGE_FILE_CHECKMK_PASSWORD: /run/secrets/homepage_checkmk_password` | `{{HOMEPAGE_FILE_CHECKMK_PASSWORD}}` |

For a second Checkmk with different credentials, add a suffix such as `_2` to each name.
