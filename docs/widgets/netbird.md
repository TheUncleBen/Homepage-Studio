# NetBird

Mesh VPN. Online Peers, Users, Login Expired.

Integration · type `netbird` · [Homepage documentation](https://gethomepage.dev/widgets/services/netbird/)

[All widgets](README.md)

## What it needs

Learn more about [NetBird](https://netbird.io).

You will need a [personal access token](https://docs.netbird.io/manage/public-api) from an account with the `Admin` role, preferably a service user.

By default `online` and `users` are shown. `login_expired` (peers whose login has expired) is optional.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `https://netbird.host.or.ip`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `online`, `users`, `login_expired`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_netbird_key` | `HOMEPAGE_FILE_NETBIRD_KEY: /run/secrets/homepage_netbird_key` | `{{HOMEPAGE_FILE_NETBIRD_KEY}}` |

For a second NetBird with different credentials, add a suffix such as `_2` to each name.
