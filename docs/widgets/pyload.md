## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_pyload_password` | `HOMEPAGE_FILE_PYLOAD_PASSWORD: /run/secrets/homepage_pyload_password` | `{{HOMEPAGE_FILE_PYLOAD_PASSWORD}}` |
| API key | `homepage_pyload_key` | `HOMEPAGE_FILE_PYLOAD_KEY: /run/secrets/homepage_pyload_key` | `{{HOMEPAGE_FILE_PYLOAD_KEY}}` |

For a second pyLoad with different credentials, add a suffix such as `_2` to each name.
