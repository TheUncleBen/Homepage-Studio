## What it needs

Learn more about [Trilium](https://github.com/TriliumNext/Notes).

This widget is compatible with [TriliumNext](https://github.com/TriliumNext/Notes) versions >= [v0.94.0](https://github.com/TriliumNext/Notes/releases/tag/v0.94.0).

Find (or create) your ETAPI key under `Options > ETAPI > Create new ETAPI token`.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `https://trilium.host.or.ip`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `version`, `notesCount`, `dbSize`. The widget shows them in the order you list them. Leave unset for its usual fields. |
