## What it needs

Learn more about [HDHomerun](https://www.silicondust.com/support/downloads/).

If more than 4 fields are provided, only the first 4 are displayed.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://hdhomerun.host.or.ip`. |
| Tuner | `tuner` | Number | Example: `0`. |
| Visible fields | `fields` | List | Choices: `channels`, `hd`, `tunerCount`, `channelNumber`, `channelNetwork`, `signalStrength`, `signalQuality`, `symbolQuality`, `networkRate`, `clientIP`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: hdhomerun
  url: http://hdhomerun.host.or.ip
  tuner: 0 # optional - defaults to 0, used for tuner-specific fields
  fields: ["channels", "hd"] # optional - default fields shown
```
