## What it needs

Learn more about [Traefik](https://github.com/traefik/traefik).

No extra configuration is required. If your traefik install requires authentication, include the username and password used to login to the web interface.

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| Password | `homepage_traefik_password` | `HOMEPAGE_FILE_TRAEFIK_PASSWORD: /run/secrets/homepage_traefik_password` | `{{HOMEPAGE_FILE_TRAEFIK_PASSWORD}}` |

For a second Traefik with different credentials, add a suffix such as `_2` to each name.
