# Emby

## What it needs

> **Studio note:** The fields selection controls count blocks, which require enableBlocks: true. Now Playing remains independently configurable.

Learn more about [Emby](https://github.com/MediaBrowser/Emby).

You can create an API key from inside Emby at `Settings > Advanced > Api Keys`.

As of v0.6.11 the widget supports fields `["movies", "series", "episodes", "songs"]`. These blocks are disabled by default but can be enabled with the `enableBlocks` option, and the "Now Playing" feature (enabled by default) can be disabled with the `enableNowPlaying` option.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://emby.host.or.ip`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Enable Blocks | `enableBlocks` | On/off | Example: `true`. |
| Enable Now Playing | `enableNowPlaying` | On/off | Example: `true`. |
| Enable User | `enableUser` | On/off | Example: `true`. |
| Enable Media Control | `enableMediaControl` | On/off | Example: `false`. |
| Show Episode Number | `showEpisodeNumber` | On/off | Example: `true`. |
| Expand One Stream To Two Rows | `expandOneStreamToTwoRows` | On/off | Example: `false`. |
| Visible fields | `fields` | List | Choices: `movies`, `series`, `episodes`, `songs`. The widget shows them in the order you list them. Leave unset for its usual fields. |
