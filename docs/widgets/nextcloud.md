# Nextcloud

File sync and collaboration. Cpu Load, Memory Usage, Free Space, Active Users, Files, Shared Items.

Integration · type `nextcloud` · [Homepage documentation](https://gethomepage.dev/widgets/services/nextcloud/)

[All widgets](README.md)

## What it needs

Learn more about [Nextcloud](https://github.com/nextcloud).

Use username & password, or the `NC-Token` key. Information about the token can be found under **Settings** > **System**. If both are provided, NC-Token will be used.

Note "cpuload" and "memoryusage" were deprecated in v0.6.18 and a maximum of 4 fields can be displayed.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `https://nextcloud.host.or.ip:port`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Username | `username` | Text | Example: `username`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Visible fields | `fields` | List | Choices: `cpuload`, `memoryusage`, `freespace`, `activeusers`, `numfiles`, `numshares`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_nextcloud_key` | `HOMEPAGE_FILE_NEXTCLOUD_KEY: /run/secrets/homepage_nextcloud_key` | `{{HOMEPAGE_FILE_NEXTCLOUD_KEY}}` |
| Password | `homepage_nextcloud_password` | `HOMEPAGE_FILE_NEXTCLOUD_PASSWORD: /run/secrets/homepage_nextcloud_password` | `{{HOMEPAGE_FILE_NEXTCLOUD_PASSWORD}}` |

For a second Nextcloud with different credentials, add a suffix such as `_2` to each name.
