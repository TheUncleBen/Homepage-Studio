# Jellyfin

Media server. Movies, Series, Episodes, Songs, Albums.

Integration · type `jellyfin` · [Homepage documentation](https://gethomepage.dev/widgets/services/jellyfin/)

[All widgets](README.md)

## What it needs

Learn more about [Jellyfin](https://github.com/jellyfin/jellyfin).

You can create an API key from inside the Jellyfin Administration Dashboard under `Advanced > API Keys`.

By default blocks are disabled and 'Now Playing' is enabled. You can toggle these settings using the enableBlocks and enableNowPlaying options.

| Jellyfin Version | Homepage Widget Version |
| --- | --- |
| < 12 (10.12) | 1 (default) |
| >= 12 (10.12) | 2 |

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://jellyfin.host.or.ip:port`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Jellyfin version | `version` | Number | A choice in the dialog: Before 10.12 (`1`, the default when left out), 10.12 or later (`2`). Which Jellyfin you run, so the widget uses the matching API. Homepage can't detect it. |
| Enable Blocks | `enableBlocks` | On/off | Example: `true`. |
| Enable Now Playing | `enableNowPlaying` | On/off | Example: `true`. |
| Enable User | `enableUser` | On/off | Example: `true`. |
| Enable Media Control | `enableMediaControl` | On/off | Example: `false`. |
| Show Episode Number | `showEpisodeNumber` | On/off | Example: `true`. |
| Expand One Stream To Two Rows | `expandOneStreamToTwoRows` | On/off | Example: `false`. |
| Visible fields | `fields` | List | Choices: `movies`, `series`, `episodes`, `songs`, `albums`. Leave unset for its usual fields. |

## Keeping its secrets out of the files

Store each as a Docker secret ([DEPLOY.md](../DEPLOY.md#widget-api-keys-as-docker-secrets)) with exactly these names:

| Setting | Docker secret | Environment variable | Enter in the setting |
| --- | --- | --- | --- |
| API key | `homepage_jellyfin_key` | `HOMEPAGE_FILE_JELLYFIN_KEY: /run/secrets/homepage_jellyfin_key` | `{{HOMEPAGE_FILE_JELLYFIN_KEY}}` |

For a second Jellyfin with different credentials, add a suffix such as `_2` to each name.

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: jellyfin
  url: http://jellyfin.host.or.ip:port
  key: apikeyapikeyapikeyapikeyapikey
  version: 2 # optional, default is 1
  enableBlocks: true # optional, defaults to false
  enableNowPlaying: true # optional, defaults to true
  enableUser: true # optional, defaults to false
  enableMediaControl: false # optional, defaults to true
  showEpisodeNumber: true # optional, defaults to false
  expandOneStreamToTwoRows: false # optional, defaults to true
```
