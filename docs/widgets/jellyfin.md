## What it needs

Learn more about [Jellyfin](https://github.com/jellyfin/jellyfin).

You can create an API key from inside the Jellyfin Administration Dashboard under `Advanced > API Keys`.

By default blocks are disabled and 'Now Playing' is enabled. You can toggle these settings using the enableBlocks and enableNowPlaying options.

| Jellyfin Version | Homepage Widget Version |
| --- | --- |
| < 12 (10.12) | 1 (default) |
| >= 12 (10.12) | 2 |

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `http://jellyfin.host.or.ip:port`. |
| API key | `key` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Version | `version` | Number | Example: `2`. |
| Enable Blocks | `enableBlocks` | On/off | Example: `true`. |
| Enable Now Playing | `enableNowPlaying` | On/off | Example: `true`. |
| Enable User | `enableUser` | On/off | Example: `true`. |
| Enable Media Control | `enableMediaControl` | On/off | Example: `false`. |
| Show Episode Number | `showEpisodeNumber` | On/off | Example: `true`. |
| Expand One Stream To Two Rows | `expandOneStreamToTwoRows` | On/off | Example: `false`. |
| Visible fields | `fields` | List | Choices: `movies`, `series`, `episodes`, `songs`, `albums`. The widget shows them in the order you list them. Leave unset for its usual fields. |
