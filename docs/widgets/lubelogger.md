# LubeLogger

Integration · type `lubelogger` · [Homepage documentation](https://gethomepage.dev/widgets/services/lubelogger/)

[All widgets](README.md)

## What it needs

Learn more about [LubeLogger](https://github.com/hargata/lubelog) (v1.3.7 or higher is required).

The widget comes in two 'flavors', one shows data for all vehicles or for just a specific vehicle with the `vehicleID` parameter.

## Settings

What the widget dialog shows. Anything else the widget accepts goes in the dialog's YAML view.

| Setting | YAML key | Type | Notes |
| --- | --- | --- | --- |
| Service URL | `url` | Text | Example: `https://lubelogger.host.or.ip`. |
| Username | `username` | Text | Example: `lubeloggerusername`. |
| Password | `password` | Text | Secret: hidden while you type. Prefer a `{{HOMEPAGE_VAR_…}}` or `{{HOMEPAGE_FILE_…}}` reference. |
| Vehicle ID | `vehicleID` | Number | Example: `1`. |
| Visible fields | `fields` | List | Choices: `vehicles`, `serviceRecords`, `reminders`. The widget shows them in the order you list them. Leave unset for its usual fields. |

## Examples

From Homepage's documentation. Values are examples, not defaults.

```yaml
widget:
  type: lubelogger
  url: https://lubelogger.host.or.ip
  username: lubeloggerusername
  password: lubeloggerpassword
  vehicleID: 1 # optional, changes to single-vehicle version
```
