The acceptance harness scanned `/proc/<pid>/cmdline` for an argument exactly
equal to `/app/homepage/server.js`. The pinned Next.js 16.3.8 startup code assigns
`process.title` to its own server title, replacing that command line on Linux.
The scanner consequently excluded running native workers. Native listeners and
the preceding native-page readiness checks had succeeded.

The correction must identify direct renderer children through their explicit
dashboard/instance environment, exact renderer working directory and controller
parent relationship. It must preserve the exact worker count, UID 1000,
dashboard-specific configuration directory, loopback listener and disabled MCP
write assertions. A real child-process regression must exercise the changed
process title; removing the assertion or matching another display title would
leave the discovery error unresolved.

This diagnosis does not complete the later container gates. The corrected
